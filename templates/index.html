GRAMMAR

Expression rules

Program   → Statement EOF
Statement → IDENTIFIER '=' Expr | Expr
Expr      → Term (('+' | '-') Term)*
Term      → Unary (('*' | '/') Unary)*
Unary     → '-' Unary | Primary
Primary   → NUMBER | IDENTIFIER | '(' Expr ')'

Multiplication and division bind more tightly because Term is parsed inside Expr. Repetition makes operators left-associative; parentheses override the default grouping.
